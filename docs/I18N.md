# Website translations

The website uses Django gettext, lazy translation for form/model labels, template `translate`/`blocktranslate`, and standard gettext PO/MO catalogues. Chinese source messages provide the fallback. English, Japanese and Korean translations live in `locale/`.

`AccountLocaleMiddleware`, placed after authentication, activates the authenticated user's saved language or an anonymous explicit session choice. Its scoped activation avoids leaking language between requests. It sets `Content-Language` and varies responses by Cookie. The public language form is CSRF-protected. Account language is never taken from an unvalidated redirect, browser locale or an untrusted service field.

Use complete messages with named variables and plural forms, not translated fragments. Keep user data escaped. Password-reset and verification emails use the recipient's preference. Templates use localized Django date formats. The language picker uses native names.

## Development and release

GNU gettext (`msgfmt`, `xgettext`) must be available locally. `scripts/dev.sh` compiles the catalogues before starting the server. The Docker image installs gettext and compiles catalogues at build time; generated `.mo` files are not committed.

```sh
.venv/bin/python manage.py makemessages -l en -l ja -l ko --ignore=.venv --ignore=.data --ignore=staticfiles --no-wrap
# Translate new entries in locale/*/LC_MESSAGES/django.po, then:
.venv/bin/python manage.py compilemessages --ignore=.venv --ignore=.data
.venv/bin/python manage.py test accounts --settings=config.test_settings
.venv/bin/ruff check .
```

Deploy the SSO migration and updated service before the Fanmade API and frontend. The API change is additive; older clients can ignore the field, and the updated frontend defaults to Chinese if an older service omits it. No business database migration or reimport of accounts is needed. Run normal `manage.py migrate` during release; do not rerun the earlier account migration/import.

Reference: [Django 5.2 translation documentation](https://docs.djangoproject.com/en/5.2/topics/i18n/translation/).
